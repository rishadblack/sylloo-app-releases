# Sylloo App downloads

Sylloo App is the staff window onto your Sylloo business: sign in once with your browser, then open your business in its own window.

| | Download |
|---|---|
| **Windows** (10 and 11, 64-bit) | [sylloo-app-setup.exe](https://github.com/rishadblack/sylloo-app-releases/releases/latest/download/sylloo-app-setup.exe) |
| **Android** (8.0 and newer) | [sylloo-app.apk](https://github.com/rishadblack/sylloo-app-releases/releases/latest/download/sylloo-app.apk) |

These links always give the newest version. Older versions are on the [Releases](https://github.com/rishadblack/sylloo-app-releases/releases) page.

## Install

- **Windows**: run `sylloo-app-setup.exe`. If Windows shows "Windows protected your PC", choose **More info › Run anyway**.
- **Android**: open `sylloo-app.apk` on the phone. Android asks once to allow installing apps from your browser or files app; allow it, then tap **Install**. Sylloo App is not on Google Play.

## Updates

Sylloo App updates itself. It checks for a new version when it starts (and from its menu: **Check for updates**). Every update is signed; the app installs only files signed with the Sylloo App key.

`latest.json` in each release is that signed update feed. Do not rename this repository or the files: installed apps read them.

This repository holds no app code.
